"# House_Price_Prediction" 
1. Linear Regression
 
 Basic regression model
 Assumes linear relationship between features and price
 Often used as a baseline model
2. Decision Tree Regressor
 
 Splits data into decision rules (tree structure)
 Can capture non-linear relationships
3. Random Forest Regressor
 
 Ensemble of multiple decision trees
 Improves accuracy and reduces overfitting
4. Gradient Boosting Regressor
 
 Sequential boosting method
 Each new model corrects previous errors
5. XGBoost Regressor
 
 Advanced boosting algorithm
 Usually gives best performance in house price prediction tasks
